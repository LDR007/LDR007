## 🚀 Featured projects

### 📚 Study Guide — Informatica & Sistemi e Reti

An interactive study guide focused on Informatica and Sistemi e Reti.

The project includes a modern responsive interface, live search, SPA-style
navigation, syntax highlighting, reading progress and print optimization.

**Topics include:** SQL, PHP, PDO, E-R model, relational model, relational
algebra, normalization, ISO/OSI, TCP/IP, VLAN, subnetting, OSPF, DNS, DHCP,
firewalls, VPNs and cryptography.
